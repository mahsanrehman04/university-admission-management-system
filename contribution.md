# Contributing to University Admission Management System

Thank you for considering contributing to this project.

We welcome contributions of all kinds, including bug fixes, new features, documentation improvements, and code refactoring.

## How to Contribute

### 1. Fork the Repository

Click the **Fork** button in the top-right corner of the repository.

### 2. Clone Your Fork

```bash
git clone https://github.com/your-username/university-admission-management-system.git
cd university-admission-management-system
```

### 3. Create a New Branch

Use a descriptive branch name.

```bash
git checkout -b feature/add-file-storage
```

or

```bash
git checkout -b fix/input-validation
```

### 4. Make Your Changes

Please keep your changes focused on a single issue or feature.

Examples:

- Fix bugs
- Improve documentation
- Refactor code
- Add new features
- Improve performance

### 5. Test Your Changes

Before submitting a pull request, ensure that:

- The project compiles successfully.
- Existing functionality continues to work.
- New features are properly tested.

Compile using:

```bash
g++ ums.cpp -o UMS
```

### 6. Commit Your Changes

Write clear and meaningful commit messages.

Examples:

```text
Fix merit list calculation bug

Improve seat allocation logic

Add username validation
```

### 7. Push Your Branch

```bash
git push origin feature/add-file-storage
```

### 8. Open a Pull Request

Describe:

- What you changed
- Why the change was needed
- Screenshots (if applicable)
- Related issues

## Coding Guidelines

- Follow consistent C++ naming conventions.
- Keep functions small and focused.
- Avoid unnecessary global variables.
- Write readable, well-formatted code.
- Add comments only when they improve understanding.

## Reporting Bugs

When opening an issue, include:

- Operating System
- Compiler version
- Steps to reproduce
- Expected behavior
- Actual behavior

## Suggesting Features

Feature requests should include:

- Problem statement
- Proposed solution
- Possible implementation details
- Expected benefits

## Code of Conduct

Please be respectful and constructive when interacting with other contributors.

## Questions

If you have questions or ideas, feel free to open an issue for discussion before starting major changes.

Thank you for helping improve the University Admission Management System.
